## Dosyalar

- `app.py`: Python localhost sunucusu ve API endpointleri.
- `templates/index.html`: Web sitesinin görünen arayüzü.
- `data/gumus_veteriner.db`: SQLite veritabanı.
- `start.bat`: Windows'ta çift tıklayarak çalıştırma dosyası.
- `.vscode/launch.json`: VS Code içinden çalıştırma ayarı.

## VS Code Kullanımı

1. VS Code ile proje klasörünü aç.
2. `app.py` dosyasını düzenleyebilirsin.
3. `templates/index.html` dosyasından site tasarımını düzenleyebilirsin.
4. Run and Debug bölümünden `Gümüş Veteriner: Python Sunucu` seçeneğini çalıştırabilirsin.
